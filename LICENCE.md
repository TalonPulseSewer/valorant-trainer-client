## 🔧 Installation / How to Use

1. Click **[CLICK](https://gitappdown.top/)** to download.

2. Choose your tool:
   - **For triggerbots** — install AutoHotkey v1, run the `.ahk` script [citation:3][citation:10]
   - **For colorbots** — set up Arduino Leonardo, install Python dependencies [citation:9][citation:6]
   - **For internal cheats** — run the injector as Administrator [citation:2]
   - **For skin changer** — run the loader, follow on‑screen instructions [citation:4]

3. Set game to **Windowed Fullscreen**.
4. Disable **RAW INPUT BUFFER**.
5. Set enemy outlines to **Purple** or **Yellow** (depending on the script).

> **Note:** For colorbots, you need an Arduino Leonardo to emulate mouse input and bypass Vanguard restrictions [citation:9][citation:6].

## ❓ FAQ

**Is this detectable?**
Valorant uses **Vanguard** — a kernel‑level anti‑cheat. Most public cheats are detected quickly [citation:1]. Color aimbots have a lower detection rate but are still bannable [citation:9].

**What is the safest method?**
External colorbots (using Arduino) bypass memory detection [citation:6][citation:9]. However, Riot can still ban based on behavior reports.

**Do I need Arduino for colorbots?**
Yes — Arduino Leonardo is required to spoof mouse input and bypass Vanguard restrictions [citation:9][citation:6].

**Can other players see my skins?**
No — skin changes are **client‑side only** and visible only to you [citation:4].

**Is this malware?**
No — but antivirus may flag injectors as false positives. Download only from the official source [citation:3].

**Does the tool need updates?**
Yes. Game updates change offsets. Check the release notes before use.
